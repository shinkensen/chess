# BetChess

A prediction market for lichess live streamed games.
It uses the lichess api to stream games right to you and runs a prediction market on top of that. At any given time there will be ~2 live games


You get 500 credits on signup and play against bots of 3 flavors, aggressive, middle, and conservative

These 3 bots also use StockFish to analyze current positions and make bets based off that

Like a real prediction market, you can buy and sell at any time. Make an account and start playing today!

The goal is to make the most money possible. Oh yea this is also multiplayer so the more the merrier
